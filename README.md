# Healthcare Automation

## Overview

This project automates downloading, extracting, processing, and storing CMS healthcare data using Python.

## Features

- Automatically downloads CMS files
- Extracts ZIP files
- Processes HCPCS and Physician payment data
- Stores processed data into MySQL
- Modular Python project

## Technologies Used

- Python
- Selenium
- Pandas
- MySQL
- Requests
- Zipfile
